# WeatherApp iOS

Минималистичное приложение прогноза погоды для iOS, разработанное с использованием **SwiftUI**, архитектурного паттерна **MVVM** и фреймворка реактивности **Apple Observation**.

---

## Иерархия файлов и структура проекта

## Как реализована память приложения

В приложении используется сбалансированная **двухуровневая модель работы с данными**: оперативная память для быстрого рендеринга и дисковая память для долговременного хранения.

### 1. Оперативная память (In-Memory / Runtime State)
- **Где размещается**: В куче (Heap) в рамках жизненного цикла приложения.
- **Владение объектами**: Корневая структура `WeatherApp` хранит экземпляры ViewModels как `@State`. Это гарантирует, что модели не пересоздаются при обновлении интерфейса:
  ```swift
  @State private var weatherVM = WeatherViewModel()
  @State private var cityListVM = CityListViewModel()
  @State private var settingsVM = SettingsViewModel()
  ```
- **Фреймворк Observation (`@Observable`)**:
  - В отличие от устаревшего Combine (`ObservableObject` + `@Published`), макрос `@Observable` отслеживает чтение конкретных полей на этапе вызова `body` у `View`.
  - Если во `WeatherViewModel` обновился только статус загрузки `isLoading`, то перерисуется только индикатор загрузки, а тяжелые карточки прогнозов не будут тратить ресурсы на пересчет.
- **Какие данные живут только в RAM**:
  - Полный агрегат данных `CityWeather` (24 почасовые точки, 7 дней прогноза, динамические метеопараметры).
  - Кэш карточек для экрана городов (`savedCitiesWeather`), чтобы при открытии списка локации отрисовывались мгновенно со сложностью $O(1)$.
  - Буфер поискового запроса (`searchQuery`, `searchResults`) и активная задача отмены дебаунса (`Task.cancel()`).

### 2. Долговременная память на диске (Persistent Storage)
В проекте реализовано чистое разделение сфер ответственности (Separation of Concerns):
- **Системное хранилище `UserDefaults`**:
  1. **Список избранных городов (`favoriteCities`)**: массив объектов `City`, кодируемый в бинарный JSON (`Data`) через `JSONEncoder`.
  2. **Идентификатор активного города (`lastSelectedCityId`)**: строковое представление UUID последнего просмотренного города для открытия на том же месте.
  3. **Тема оформления (`appTheme`)**: значение строкового перечисления ("system", "dark", "light").
- **База данных `SwiftData` (кэширование погоды)**:
  - Реализована через сущность `@Model CachedWeatherItem` (`cityId`, `cityName`, `weatherData`, `cachedAt`).
  - Управляется через нативные `ModelContainer` и `ModelContext`.
  - **Сразу после получения данных**: при успешном запросе актуальный `CityWeather` сохраняется в SwiftData.
  - **Перед уходом в спящий режим**: хук `@Environment(\.scenePhase)` (`.inactive` / `.background`) в `WeatherApp` гарантирует вызов `saveStateBeforeSleep()` и запись свежих данных в SwiftData.
  - **Офлайн-режим**: если сеть недоступна, приложение считывает кэш из SwiftData и показывает данные с бейджем «Офлайн-режим».

## Основные функции приложения

### 1. Главный экран погоды
- **Текущее состояние**: город, описание условий, температура в **°C**, дневной диапазон (мин/макс) и «ощущается как».
- **Почасовой прогноз (24 часа)**: плавная горизонтальная карусель со временем, погодными иконками, вероятностью осадков в % и температурой.
- **Прогноз на 7 дней**: компактный список с визуальной шкалой температурного разброса дня относительно недели и индикатором текущей температуры.
- **Метеорологические карточки (СИ)**:
  - **Ветер**: скорость в **м/с**, текстовое направление и сила порывов;
  - **Давление**: в **гПа** с оценкой нормы;
  - **Влажность**: процент влажности и точка росы (°C);
  - **УФ-индекс**: числовой уровень и текстовая рекомендация;
  - **Видимость**: расстояние в **км**;
  - **Восход и закат**: точное астрономическое время.
- **Адаптивный фон**: подстраивается под тип погоды (ясно, дождь, снег, гроза) и автоматически переключается между пастельными тонами для светлой темы и глубокими оттенками для тёмной.
- **Жесты и геолокация**: поддержка обновления свайпом вниз (*pull-to-refresh*) и мгновенный запрос погоды по GPS.

### 2. Экран городов
- **Поиск и каталог**: быстрый поиск по городам и регионам России с задержкой ввода (дебаунс 300 мс).
- **Список избранного**: наглядные карточки с локальным временем и текущей температурой каждого города.
- **Управление**: добавление городов в одно касание, удаление свайпом (*swipe-to-delete*), сохранение порядка.

### 3. Экран настроек
- **Темы оформления**: выбор между системной, тёмной и светлой темой интерфейса.

## Стек технологий
- **Платформа**: iOS 18+ (iPhone / iPad)
- **UI**: SwiftUI (минималистичный нативный интерфейс)
- **База данных и кэш**: SwiftData (`@Model CachedWeatherItem`)
- **Настройки и избранное**: UserDefaults (JSON Codable)
- **Архитектура**: MVVM (Model-View-ViewModel)
- **Реактивность**: Apple Observation (`@Observable`)
- **Геолокация**: CoreLocation (асинхронный Swift Concurrency)
- **Тестирование**: Swift Testing (`@Test`, `#expect`)
