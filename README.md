# WeatherApp iOS

Минималистичное приложение прогноза погоды для iOS, разработанное с использованием **SwiftUI**, архитектурного паттерна **MVVM** и фреймворка реактивности **Apple Observation**.

---

## Архитектура 4 экранов

Приложение построено на базе 4 специализированных экранов:
1. **Экран 1 (Главный экран, `WeatherMainView`)**: Детальная сводка погоды по выбранному городу, почасовой прогноз (24 часа), прогноз на 7 дней с датами, метеокарточки в системе СИ (°C, м/с, гПа, км), индикатор давности кэша и всплывающее уведомление об отсутствии интернета.
2. **Экран 2 (Список избранного, `CityListView`)**: Отображение **только избранных городов** с их текущей температурой и статусом погоды. Быстрый переход к экрану добавления/поиска через кнопку **«+»** в панели навигации, удаление свайпом (*swipe-to-delete*).
3. **Экран 3 (Настройки, `SettingsView`)**: Мгновенное переключение темы приложения (системная, темная, светлая) и справочная информация.
4. **Экран 4 (Поиск и добавление, `AddCityView`)**: Выделенный экран поиска городов России с дебаунсом 300 мс, каталог популярных локаций и мгновенное добавление в избранное в одно касание.

## Иерархия файлов и структура проекта

│   ├── AppSettings.swift                   # MetricFormatter (форматирование СИ: °C, м/с, гПа) и AppTheme (темы)

## Как реализована память приложения

В приложении используется сбалансированная **двухуровневая модель работы с данными**: оперативная память для мгновенного рендеринга и дисковая память для сохранения данных между запусками.

### 1. Оперативная память (In-Memory / Runtime State)
- **Владение объектами**: Корневая структура `WeatherApp` хранит экземпляры ViewModels как `@State`. Это гарантирует сохранение состояния при повторных перерисовках интерфейса:
  ```swift
  @State private var weatherVM = WeatherViewModel()
  @State private var cityListVM = CityListViewModel()
  @State private var settingsVM = SettingsViewModel()
  ```
- **Фреймворк Observation (`@Observable`)**:
  - Макрос `@Observable` обеспечивает гранулярное отслеживание изменений. Обновление отдельного поля приводит к перерисовке только тех View, которые напрямую читают это свойство.
- **Данные в RAM**:
  - Полный агрегат данных `CityWeather` текущего города (24 точки почасового прогноза, 7 дней суточного прогноза с датами, расширенные метеорологические параметры).
  - Кэш для карточек избранных городов (`savedCitiesWeather`) со сложностью доступа $O(1)$.
  - Буфер поисковых запросов и дебаунс-задачи (`searchTask`).

### 2. Долговременная память на диске (Persistent Storage)
- **Системное хранилище `UserDefaults`**:
  1. **Список избранных городов (`favoriteCities`)**: массив объектов `City` в бинарном JSON (`Data`).
  2. **Идентификатор активного города (`lastSelectedCityId`)**: UUID последнего просмотренного города.
  3. **Тема оформления (`appTheme`)**: строковый ключ темы ("system", "dark", "light").
- **База данных `SwiftData` (кэширование погоды)**:
  - Реализована через сущность `@Model CachedWeatherItem` (`cityId`, `cityName`, `weatherData`, `cachedAt`).
  - **Сразу после получения данных**: при успешном ответе данные погоды записываются в SwiftData.
  - **Перед уходом в спящий режим**: хук `@Environment(\.scenePhase)` (`.inactive` / `.background`) в `WeatherApp` вызывает `saveStateBeforeSleep()`.
  - **Офлайн-режим**: если сеть отсутствует, приложение берет данные из SwiftData и показывает статус с точным временем последнего обновления.

## Особенности реализации требований

1. **Только избранные города на экране 2 (`CityListView`)**:
   - Поисковая строка перенесена на отдельный экран;
   - Список содержит только добавленные пользователем локации;
   - В навигационной панели добавлена кнопка **«+»**, открывающая экран поиска и добавления.
2. **Экран 4 поиска и добавления (`AddCityView`)**:
   - Реализован как отдельный экран с нативным `.searchable`;
   - Быстрый выбор из каталога популярных российских городов;
   - Кнопка **«+»** для добавления в избранное с индикацией уже добавленных городов.
3. **Обновленный 7-дневный прогноз (`DailyForecastView`)**:
   - Линия солнечного дня (шкала диапазона) полностью удалена;
   - Добавлено форматированное отображение даты (например, «Сегодня / 2 окт.», «Пн / 6 окт.»);
   - Сбалансированная 3-колоночная компоновка: дата и день недели слева, иконка и вероятность осадков по центру, максимум и минимум температуры справа.
4. **Полное удаление геолокации устройства**:
   - Удалены фреймворк CoreLocation, сервис `LocationService`, кнопки запроса GPS, поля `isCurrentLocation` и описания разрешений геолокации из `Info.plist`.
5. **Всплывающее уведомление об отсутствии интернета**:
   - Сервис `NetworkMonitor` на базе `NWPathMonitor` отслеживает состояние сети в реальном времени;
   - При отсутствии подключения или ошибке сети поверх интерфейса появляется анимированный плавающий баннер с кнопкой закрытия и автоматическим скрытием через 3.5 секунды.

## Стек технологий
- **Платформа**: iOS 18+ (iPhone / iPad)
- **UI**: SwiftUI (минималистичный нативный интерфейс)
- **База данных и кэш**: SwiftData (`@Model CachedWeatherItem`)
- **Настройки и избранное**: UserDefaults (JSON Codable)
- **Архитектура**: MVVM (Model-View-ViewModel)
- **Реактивность**: Apple Observation (`@Observable`)
- **Сетевой мониторинг**: Network (`NWPathMonitor`)
- **Тестирование**: Swift Testing (`@Test`, `#expect`)
